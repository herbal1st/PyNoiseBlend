===============================================================================
                 PYNOISEBLEND - CONFIGURATION MANUAL & FIELD GUIDE
===============================================================================

[!] CROSS-REFERENCE NOTICE:
    - This manual covers global runtime and simulation variables in config.py.
    - Specialized recipes for spatial chunking, procedural noise algorithms,
      composite world builds, strata color ramps, and solar lighting have
      dedicated legends directly inside their respective YAML files in the
      profiles/ folder.
    - For system architecture specifications, math formulas, and memory
      flow rules, refer to README.md.


[DISPLAY & RESOLUTION SETTINGS]
-------------------------------------------------------------------------------
APP_TITLE                     : Text displayed on the operating system window
                                frame and taskbar.
                                Metric: Text string (str).

SCREEN_WIDTH                  : Width of the application window in pixels.
                                Metric: Pixels (int).

SCREEN_HEIGHT                 : Height of the application window in pixels.
                                Metric: Pixels (int).

FPS                           : Maximum simulation refresh rate cap. Dictates
                                animation smoothness, camera fluidity, and
                                internal frame timing.
                                Metric: Frames per second / Hertz (int).

BACKGROUND_COLOR              : Canvas clear color drawn behind the 1D wave
                                oscilloscope curves in Mode 1.
                                Metric: RGB color tuple (int, int, int).


[VIEWPORT & STEPPING MODES]
-------------------------------------------------------------------------------
DEFAULT_VIEW_MODE             : Studio viewport loaded immediately on boot:
                                  1 = Mode 1: 1D Wave Oscilloscope
                                  2 = Mode 2: 2D Spatial Synthesizer
                                  3 = Mode 3: Raw Procedural Noise Explorer
                                  4 = Mode 4: Endless Procedural World Explorer
                                  5 = Mode 5: Solar Lighting Studio
                                Metric: Mode selector [1 - 5] (int).

DEFAULT_TILE_SIZE             : Default block width and height when retro tile
                                pixelation is toggled on.
                                Metric: Pixels (int).

MIN_TILE_SIZE                 : Smallest tile block size permitted when cycling
                                stepping finer with Shift+Space.
                                Metric: Pixels (int).

MAX_TILE_SIZE                 : Largest tile block size permitted before
                                discrete stepping wraps back around to smooth.
                                Metric: Pixels (int).

WARP_FACTOR                   : Curvature strength used by Mode 2's Warped
                                view. Controls how strongly the continental
                                crust or relief layer bends straight vertical
                                base ridges into winding, organic mountains.
                                Metric: Fraction multiplier [0.0 - 1.0] (float).


[RELIEF NET (ISOLINE) SETTINGS]
-------------------------------------------------------------------------------
DEFAULT_NET_ENABLED           : Initial state of the Topographical Relief Net
                                (contour line blueprint) on launch. In Mode 1,
                                swaps solid ribbon fills for a colored line;
                                in Modes 2-5, swaps textured terrain for
                                razor-sharp elevation isolines.
                                Metric: Toggle boolean (bool).

DEFAULT_NET_INTERVALS         : Number of elevation steps slicing terrain from
                                sea level (0.0) to mountain summits (1.0). N
                                steps create N + 1 distinct contour lines.
                                Metric: Slice count (float).

DEFAULT_NET_BANDWIDTH         : Line thickness tolerance used in smooth mode
                                to draw continuous, unbroken contour bands.
                                Metric: Normalized height tolerance (float).

COLOR_NET_BACKGROUND          : Slate background color drawn behind contour
                                lines when Relief Net view is active.
                                Metric: RGB color tuple (int, int, int).


[MATHEMATICAL ELEVATION BUDGETS]
-------------------------------------------------------------------------------
CRUST_BUDGET                  : Maximum height share reserved for Continental
                                Crust. In budget-based formulas, CRUST_BUDGET
                                + RELIEF_BUDGET equals 1.0. This guarantees
                                mountains never flatten out against a ceiling,
                                while valleys stay naturally elevated inland.
                                Metric: Height fraction [0.0 - 1.0] (float).

RELIEF_BUDGET                 : Maximum height share reserved for local base
                                detail hills and mountain peaks.
                                Metric: Height fraction [0.0 - 1.0] (float).

MIN_RELIEF_FACTOR             : Safety floor ensuring that even in the lowest,
                                flattest plains, tiny ground undulations do
                                not vanish into total flatness.
                                Metric: Multiplier floor [0.0 - 1.0] (float).


[WAVE FREQUENCY DEFAULTS]
-------------------------------------------------------------------------------
DEFAULT_BASE_CYCLES           : Starting wave repetition count across the
                                screen for Base Detail (controls individual
                                local hills, ridges, and valleys).
                                Metric: Wave cycles across viewport (float).

DEFAULT_RELIEF_CYCLES         : Starting wave repetition count for the Relief
                                Multiplier (controls where mountains swell high
                                versus where valleys flatten into plains).
                                Metric: Wave cycles across viewport (float).

DEFAULT_CRUST_CYCLES          : Starting wave repetition count for Continental
                                Crust (the broad tectonic plate foundation).
                                Metric: Wave cycles across viewport (float).


[STARTING ELEVATION PHASE OFFSETS]
-------------------------------------------------------------------------------
BASE_START                    : Starting elevation of the Base Detail wave at
                                the left screen edge (0.00 = trough bottom,
                                0.50 = mid-slope, 1.00 = crest peak).
                                Metric: Normalized height [0.0 - 1.0] (float).

RELIEF_START                  : Starting elevation for the Relief Multiplier
                                wave at the screen origin.
                                Metric: Normalized height [0.0 - 1.0] (float).

CRUST_START                   : Starting elevation for the Continental Crust
                                wave at the screen origin.
                                Metric: Normalized height [0.0 - 1.0] (float).


[FREQUENCY TUNING RATES & CLAMPS]
-------------------------------------------------------------------------------
CYCLE_ZOOM_RATE               : Continuous scaling speed when holding Left or
                                Right Arrow keys in Modes 1 and 2 (Right zooms
                                in to wider waves; Left zooms out to tighter
                                waves), anchored at the screen center.
                                Metric: Zoom rate per second (float).

BASE_MIN_CYCLES               : Lowest and highest wave repetitions allowed
BASE_MAX_CYCLES                 for the Base Detail layer, preventing flat
                                signals or rapid visual aliasing moire.
                                Metric: Wave cycles across viewport (float).

RELIEF_MIN_CYCLES             : Safety clamping limits for Relief Multiplier
RELIEF_MAX_CYCLES               wave frequencies.
                                Metric: Wave cycles across viewport (float).

CRUST_MIN_CYCLES              : Safety clamping limits for Continental Crust
CRUST_MAX_CYCLES                tectonic wave frequencies.
                                Metric: Wave cycles across viewport (float).


[NOISE SCALE TUNING RATES & CLAMPS]
-------------------------------------------------------------------------------
NOISE_SCALE_ZOOM_RATE         : Speed at which terrain features grow or shrink
                                when holding Left or Right Arrow keys in
                                Modes 3, 4, and 5 (anchored at screen center).
                                Metric: Scale multiplier per second (float).

MOUSE_ZOOM_SENSITIVITY        : Zoom responsiveness when dragging horizontally
                                with the Right Mouse Button (RMB) held down.
                                Metric: Exponential rate per pixel (float).

NOISE_MIN_SCALE               : Smallest allowed noise feature width in pixels.
                                Prevents shrinking features so small that the
                                landscape degrades into fuzzy television static.
                                Metric: Minimum feature width in pixels (float).

NOISE_MAX_SCALE               : Largest allowed noise feature width in pixels.
                                Prevents stretching features so wide that the
                                screen looks like a single flat slope.
                                Metric: Maximum feature width in pixels (float).


[EXTENDED NOISE PARAMETER CLAMPS & STEP RATES]
-------------------------------------------------------------------------------
OCTAVE_MIN                    : Minimum detail passes stacked into a landscape.
                                At 1 octave, terrain shows only broad, smooth
                                hills with no extra crags or rough detail.
                                Metric: Octave layer count (int).

OCTAVE_MAX                    : Maximum detail passes allowed. Capped to stop
                                unnecessary math calculations from bogging down
                                lower-power computers.
                                Metric: Octave layer count (int).

DECAY_MIN                     : Smallest persistence multiplier. Makes smaller
                                detail passes fade out almost completely,
                                leaving soft, pillowy landmasses.
                                Metric: Amplitude multiplier [0.0 - 1.0] (float).

DECAY_MAX                     : Highest persistence multiplier. Keeps fine
                                detail passes strong, producing jagged, rough,
                                and craggy mountain peaks.
                                Metric: Amplitude multiplier [0.0 - 1.0] (float).

DECAY_STEP_RATE               : Speed at which persistence (roughness) shifts
                                per second when smoothly scrubbing.
                                Metric: Change per second (float).

LACUNARITY_MIN                : Smallest frequency multiplier between octaves.
                                Keeps each detail pass close to the size of the
                                one beneath it.
                                Metric: Frequency multiplier (float).

LACUNARITY_MAX                : Largest frequency multiplier between octaves.
                                Rapidly shrinks each higher detail pass into
                                extremely tight, microscopic surface ripples.
                                Metric: Frequency multiplier (float).

LACUNARITY_STEP_RATE          : Speed at which lacunarity shifts per second
                                when smoothly scrubbing.
                                Metric: Multiplier change per second (float).


[INTERACTIVE SCRUBBING THROTTLING]
-------------------------------------------------------------------------------
SCRUB_SUB_SAMPLE_FACTOR       : Lightweight grid divider used while actively
                                dragging offsets or zooming feature scales.
                                Evaluating a coarser grid cuts workload by over
                                90% for fluid 60 FPS previews; in Relief Net
                                view, coarse-cell culling keeps 1px isolines
                                sharp before snapping back to full detail.
                                Metric: Integer grid divider (int).

SCRUB_SETTLE_DELAY            : Brief rest period after releasing a keyboard
                                tuning key before the fast preview settles back
                                to full-detail rendering (mouse drag releases
                                settle instantly). Prevents quick key taps from
                                triggering unnecessary full chunk rebuilds.
                                Metric: Settle delay in seconds (float).

CHUNK_REFINE_BUDGET_PER_FRAME : Maximum number of crisp full-detail chunks
                                rebuilt per frame after tuning settles in Modes
                                3, 4, and 5. Spreads generation across frames
                                so the screen sharpens from the center outward
                                without hitching.
                                Metric: Chunks per frame (int).


[SLOPE GRADIENT DEFERRAL]
-------------------------------------------------------------------------------
ENABLE_SLOPE_GRADIENTS        : Governs whether Mode 4 world chunks calculate
                                terrain slope angles (gx, gy) and their extra
                                1-pixel border halo during generation. Keeping
                                this False during flat 2D exploration reclaims
                                25-30% chunk generation speed; Mode 5 computes
                                slopes automatically on its own lighting view.
                                Metric: Calculation toggle (bool).


[SOLAR LIGHTING STUDIO RATES & CLAMPS]
-------------------------------------------------------------------------------
LIGHT_AZIMUTH_RATE            : Speed in degrees per second at which the sun's
                                compass direction rotates when scrubbing.
                                Metric: Degrees per second (float).

LIGHT_ALTITUDE_RATE           : Speed in degrees per second at which the sun
                                rises or sinks above the horizon when scrubbing.
                                Metric: Degrees per second (float).

LIGHT_CONTRAST_MIN            : Minimum and maximum hillshading contrast
LIGHT_CONTRAST_MAX              limits, dictating how softly or dramatically
                                terrain slopes catch sunlight and cast shadows.
                                Metric: Contrast multiplier (float).

LIGHT_CONTRAST_RATE           : Rate of change when scrubbing hillshade contrast.
                                Metric: Multiplier change per second (float).

LIGHT_AMBIENT_RATE            : Rate of change when scrubbing the balance between
                                direct sunlight and soft ambient sky lighting.
                                Metric: Ratio change per second (float).

LIGHT_TIME_RATE               : Speed at which normalized time-of-day advances
                                per second when manually scrubbing time.
                                Metric: Normalized cycle per second (float).

LIGHT_EXPOSURE_MIN            : Clamping limits for flat-ground neutral
LIGHT_EXPOSURE_MAX              exposure. Keeps midday sunlight balanced so
                                sunlit slopes have room to brighten above flat
                                ground without bleaching out into pure white.
                                Metric: Exposure fraction [0.5 - 1.0] (float).

LIGHT_EXPOSURE_RATE           : Rate of change when scrubbing neutral exposure.
                                Metric: Exposure change per second (float).


[CAMERA NAVIGATION SETTINGS]
-------------------------------------------------------------------------------
TEST_PAN_SPEED                : Camera flight velocity across procedural
                                terrain in Modes 3, 4, and 5 when holding WASD.
                                Automatically scaled by delta time (dt) for
                                consistent flight speed across different PCs.
                                Metric: Pixels per second (float).


[ACTIVE PROFILE SELECTORS]
-------------------------------------------------------------------------------
ACTIVE_CHUNK_PROFILE          : Chunk sizing and memory buffer preset loaded
                                from profiles/chunk.yaml on startup.
                                Metric: Profile ID key string (str).

ACTIVE_WORLD_PROFILE          : Default world build key loaded from
                                profiles/world.yaml on startup. Dictates initial
                                world seed and layer noise presets.
                                Metric: Profile ID key string (str).

ACTIVE_LIGHTING_PROFILE       : Default solar atmosphere preset loaded from
                                profiles/lighting.yaml on startup.
                                Metric: Profile ID key string (str).


[INTERFACE COLORS]
-------------------------------------------------------------------------------
COLOR_BG                      : Deep background color used to clear the canvas
                                behind procedural terrain chunks in Modes 3-5.
                                Metric: RGB color tuple (int, int, int).

COLOR_PANEL_DIVIDER           : Light grey color used to draw horizontal
                                dividing rules between 1D oscilloscope panels.
                                Metric: RGB color tuple (int, int, int).

COLOR_GRID                    : Soft color used for interior horizontal height
                                guidelines (0.25, 0.50, 0.75) in 1D panels.
                                Metric: RGB color tuple (int, int, int).

COLOR_WAVE                    : Primary dark ink color used to draw active
                                wave curves in the 1D oscilloscope.
                                Metric: RGB color tuple (int, int, int).

COLOR_SILENCED_WAVE           : Muted grey color used to draw flat zero lines
                                for any layer silenced by a 2-layer formula
                                (such as the middle Relief layer).
                                Metric: RGB color tuple (int, int, int).

COLOR_SELECTION               : High-contrast electric blue used for active
                                panel selection frames, focused table cells,
                                footer badges, and HUD borders.
                                Metric: RGB color tuple (int, int, int).

COLOR_HUD_CARD_2D             : Translucent dark slate color drawn behind HUD
                                information boxes, spreadsheet tables, and
                                the bottom studio footer.
                                Metric: RGBA color tuple (int, int, int, int).

COLOR_HUD_TEXT_ACTIVE         : Bright yellow-gold used for active headers,
                                primary status tags, and focused mode titles.
                                Metric: RGB color tuple (int, int, int).

COLOR_HUD_TEXT_NORMAL         : Readable silver-white used for standard body
                                text across HUD cards and controls.
                                Metric: RGB color tuple (int, int, int).

COLOR_HUD_TEXT_MUTED          : Slate grey used for silenced parameters,
                                inactive layers, and table separator bars.
                                Metric: RGB color tuple (int, int, int).

COLOR_INPUT_ACTIVE            : Bright cyan glow used to highlight active
                                table cells, focused panels, and typed seeds.
                                Metric: RGB color tuple (int, int, int).
